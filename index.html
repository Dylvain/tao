01 / Prendre racine

Ton Tao.
Un lieu pour grandir.

Tao s’installe d’abord sur un ordinateur Linux. Le même cockpit s’ouvre ensuite dans le navigateur ou s’installe comme application sur un appareil compatible.

Gaïa est une porte d’entrée publique. Ton espace, tes échanges et ta mémoire vivent dans l’installation Tao que tu choisis.

Choisis ton système pour voir le chemin disponible. Tu peux changer ce choix à tout moment.

Vérification de la version…

Les informations de téléchargement sont en cours de lecture.

Installer sur Debian / Ubuntu (.deb) ↓ Autre Linux : télécharger (.run) ↓

L’installateur sera proposé lorsqu’une version signée sera disponible.

Installer sans terminal

Double-clique sur le fichier .deb, ouvre-le avec la logithèque de Debian ou Ubuntu, puis choisis Installer. Tao apparaît ensuite dans le menu des applications.

Installation sur un autre Linux

Dans le dossier téléchargé, ouvre un terminal et lance :

python3 TAO_LINUX_0.10.8.run

L’installateur indique ensuite l’adresse de ton Tao. Le dialogue demande un Codex CLI installé et connecté à ton propre compte.

Comprendre la disponibilité

Une empreinte SHA-256 permet de comparer un fichier. Elle ne prouve pas qui l’a publié. La signature et sa clé de confiance sont nécessaires pour vérifier son origine.

02 / Retrouver le fil

Le même Tao.
Un autre appareil.

Tu as déjà une installation ? Saisis son adresse pour ouvrir le cockpit. Tu pourras ensuite l’installer comme application depuis un navigateur compatible.

Le navigateur seul n’accède pas librement aux fichiers ou aux applications d’une machine : ces actions demandent un Tao local ou un appareil relié explicitement. Gaïa ne cherche aucun appareil.

Une adresse HTTPS, sans chemin ni identifiant. Sur le Linux qui héberge Tao, une adresse locale comme http://127.0.0.1:8790 est aussi acceptée.

Besoin d’aide pour relier tes appareils ?

Prépare une question à copier dans ton Tao. L’aide IA dépend du compte et des outils connectés à cette installation. Aucune connexion n’est lancée ici.

Tu décides ensuite des actions dans ton Tao. Cette question n’autorise ni appairage ni exécution.
